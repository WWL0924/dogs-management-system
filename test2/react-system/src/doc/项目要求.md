## 界面
首页 公告 注册犬只数、入口（居民/管理员）
登录注册页 填写账号密码 选身份是居民或者管理员
居民页面
首页 显示用户名
我的犬只：列表 + 新增/编辑犬只信息
犬只详情：基础信息 + 疫苗记录 + 编辑入口
投诉与举报：遛狗不牵绳、不清理粪便等
遛狗文明与社区规范：规则、处罚标准、常见问题
管理员页面
待办统计：待审核、待处理投诉等
登记审核：犬只登记审核流
犬只管理：全量犬只信息管理
投诉处理：处理记录与结果反馈
