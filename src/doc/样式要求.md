系统样式优化指令：

请在不改动业务逻辑、不修改数据结构、不删除现有功能的前提下，对当前系统样式进行整体优化。目标是提升视觉质感，使界面风格更加美观、简洁、大气、现代、统一、专业。

必须遵守以下限制：

只调整样式相关内容（CSS / SCSS / Tailwind / 主题变量 / 设计 Token）。

不修改任何 JS 逻辑代码。

不改变组件结构层级。

不新增业务依赖。

不删除现有 DOM。

不影响现有交互行为。

不降低可读性与可访问性。

不使用花哨动画。

不使用高饱和刺眼配色。

不使用杂乱渐变。

不增加视觉噪音。

不使用复杂阴影叠加。

保持留白合理。

保持整体风格统一。

保持移动端兼容。

保持主题可扩展性。

优先使用变量与可复用样式。

不写冗余样式。

不引入内联样式污染结构。

不改变原有功能语义。

优化方向：

优化间距体系

优化字体层级

优化颜色体系

优化按钮与卡片样式

优化布局对齐

优化视觉节奏

提升整体高级感与克制感

输出要求：

说明修改思路

标明修改文件

给出具体样式调整内容

不重写业务代码

不擅自扩展功能
